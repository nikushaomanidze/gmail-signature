Gmail signature: Nikoloz Omanidze (BetterStep)

FILES
- signature.html       The real signature for Gmail (has a Copy signature button).
- preview.html         Preview only. Shows the signature with the local image. Do NOT copy into Gmail.
- preview.png          Screenshot of the final look.
- images/nikoloz-banner.jpg       Banner image (340 x 360 px). Upload this one.
- images/nikoloz-photo-circle.png Round photo (200 x 200 px), spare for profiles or other designs.

STEPS
1. Upload images/nikoloz-banner.jpg to a public place (your website or server, S3/R2, GitHub raw, postimages.org).
   Do not use Google Drive, Dropbox or iCloud links.
2. Test the link in a private browser window: you should see only the image.
3. Open signature.html in a text editor and replace YOUR_BANNER_IMAGE_URL with that link. Save.
4. Double click signature.html (opens in Chrome) and click "Copy signature".
5. Gmail > Settings > See all settings > General > Signature: delete the old one, press Cmd + V, Save changes.
6. Tick "Insert this signature before quoted text in replies and remove the "--" line" to hide the -- line.
7. Do not click the image in Gmail after pasting (Small / Medium / Large would change its size).
